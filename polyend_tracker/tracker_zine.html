5. Playing, Looping & Song

Transport
  • play plays the pattern from its start. Press again to stop; again restarts from the beginning.
  • shift + play resumes from where you paused — and with a range of steps selected it loops just that range. New in OS 1.9.2, and the fastest way to work on eight bars without the other twenty-four.
  • song + play starts the song without leaving the pattern page. shift + home, stopped, resets the playhead to the top.
Changing Pattern Mid-Flight
  • pattern + ←→ queues the next pattern for the end of this one. The number blinks red while it waits.
  • pattern + ↑↓ switches immediately. So do the bare arrows, the jog and the pads.
  • Hold the Pattern screen button to see which patterns exist — lit pads are the ones with something in them.
Song Mode
  • song switches to it; holding song just peeks at it from wherever you are.
  • play starts at the current row, shift + play loops that row.
  • Tempo: song + jog, 40–800 BPM in whole beats. Add shift for 0.1 steps.
Live Recording
  • shift + rec starts it. rec alone during it keeps playing but drops out of record.
  • Arm / disarm a track: shift + rec + its screen button. Disarmed tracks refuse to record.

4. Fill

The reason a pattern gets built in a minute instead of ten. It writes a whole range of steps at once, and it is invisible if nobody shows you.

Getting There
  • In pattern, press rec — the box round the step turns red.
  • Select a range: shift + ↑↓←→.
  • Choose the column you are filling: note, inst, FX1 or FX2. It goes solid red.
  • Press Fill, the 4th screen button.
Where? — Which Steps Get Touched
  • Note / FX only overwrite steps that already have one. No Note / No FX only fill the blanks.
  • Random scatters across the range; Density sets how much of it, as a percentage.
  • Each places one every Step steps, 1–32. Straight sixteenths, or every third step.
  • Euclidean spreads Event hits, 1–32, as evenly as the length allows. Where the good rhythms come from — 8 steps, 3 events.
Fill Type — What Value Goes In
  • Constant — the same value everywhere.
  • From-To — distributed across the range. This is your ramp: a filter sweep or a pan drift written in one press.
  • Random — random values between From and To.
Scale
  • Filling notes? Pick a Scale and the fill stays in key: chromatic, major, minor, the modes, harmonic and melodic minor, phrygian dominant, bebop major.

Fill works over steps that already exist, and it ignores Step Jump. The selection is the only thing that decides where it lands.

3. Patterns & Steps

What a Step Is
  • Four columns on each of 8 tracks: note, instrument, FX1, FX2. The dedicated buttons pick which one you are editing.
  • Tap a parameter button to lock the cursor to that column while you move around.
  • Step Jump auto-advances the cursor after each entry, so you can enter every fourth step without counting.
Pattern Size
  • Hold the Pattern screen button + jog to pick a pattern, Length + jog to set its rows.
  • Extend doubles the length by inserting empty steps. Duplicate doubles it with the steps copied. Shrink halves it by deleting every second step. Also under More: Invert, Copy / Paste Pattern, Render Selection, Pattern and Track Name.
Selecting
  • shift + arrows selects a block of steps.
  • shift + ↑ on the first step selects that whole track. Press ↑ again and it takes every track.
  • copy copies, shift + copy pastes. del resets a parameter to its default; shift + del deletes the thing outright.
Seeing More Tracks
  • Four tracks show by default; ←→ walks across the rest, MIDI tracks 9–12 included.
  • pattern + note shows all 8 tracks, notes only. Same with inst, FX1, FX2.
  • Hold pattern + two of them for two columns at once. pattern alone goes back to four.
  • Mute: shift + screen button 1–8. Instant, and dimmed keys are the muted ones.

2. Anatomy & Lexicon

The Pages
  • pattern the workbench · song arrangement · perform 12 live effect slots · master mixer and FX · file load, save, export · config settings
  • Sampling side: loader browse the card · playback play modes · editor trim and process · recorder capture · inst params per-instrument
The Eight Screen Buttons
  • They mean whatever is written above them, and that changes on every page. A red underline means the option only works in rec mode; dimmed means it needs a selection first.
Global Combos
  • master + jog — master volume · song + jog — tempo, 40–800 BPM
  • shift + jog — bigger value jumps — except on tempo, where it gives 0.1 BPM instead
  • copy / shift + copy — copy / paste; del resets to default, shift + del deletes
  • shift + home — back to the top
Numbers
  • 8 audio tracks, one voice each — plus tracks 9–12, which are MIDI only, added in OS 1.9.0. Twelve in total, they always sit after track 8, and there is no way to hide them.
  • Up to 255 patterns per project. 1–128 steps per pattern, 32 by default. 128 instruments in the pool.
  • About 133 seconds of mono recording — the whole project's sample budget, not a per-take limit.
  • 7″ 800×480 screen, 4×12 pads, one jog wheel.

6. Instruments & Sampling

Eight Play Modes

An instrument is a sample plus its settings, saved as a .pti. Set how it plays on playback:

  • 1-Shot — start to end, once.
  • Forward, Backward and Pingpong loop.
  • Slice and Beat Slice — the sample cut up and spread across the notes.
  • Wavetable — the sample becomes the table of a synth.
  • Granular — grains of it, played as a cloud.
  • It is a sampler, not a stretcher: a higher note plays the sample faster, a lower one slower.
Recording
  • recorder, then pick Source: Line In, Radio, Mic LG or Mic HG. Monitor on, set Gain before you commit.
  • Everything records in mono, including a stereo line in. Which side you get is Config → General → Line in channel: Stereo, Mono Left or Mono Right.
  • You cannot sample and hear a pattern at the same time. While recording the pattern still sends MIDI out, but no audio.
  • Trim Start / End with Zoom, then Save & Load (7th button) — it writes to /Recordings and loads it into the instrument list. Plain Save only writes the file.
  • Mic in has no phantom power — dynamic mics, LG for hot ones, HG for quiet.
  • Render Selection under More bounces a selection back into a sample without leaving the box. Since 1.9.0 it cuts hard at both ends — select past the last step or you lose the reverb tail. Export Song/Pattern still keeps tails.

There is an FM radio in here and it is a legitimate source. Reception improves with a cable or aerial in the output jack.

How to Think About Them
  • An FX does not need a note in the same step. A lone filter cutoff acts on whatever is already sounding — that is how you automate.
  • Random FX (f) randomises the value of the effect in the other slot of the same step, not its own.
  • Also on the list: MIDI chords, plus one MIDI CC tag per CC slot.

8. Perform & Setup

Perform Mode
  • 12 slots, each holding one of 21 effects, played from the pads.
  • Setting it up, rec on: ←→ picks the slot, ↑↓ changes its effect, shift + ←→ swaps two slots.
  • Hold a pad + jog to set that row's value. Pad row 1 is the reset row — it returns the effect to default.
  • Playing it, rec off: a pad applies its value to the selected tracks. Held pad + jog changes a value temporarily and it snaps back on release.
  • Pick tracks with the track buttons; shift + track mutes one.
  • Live remix: track + jog swaps that track's pattern now; track + ←→ waits for the current pattern to end.
  • The perform preset is saved globally by default. Config switches it to per-project.
Round the Back
  • 3.5mm out (headphones too), line in, mic in, MIDI out, MIDI in — Type B adapters, so a Type A cable will not work.
  • Micro SD, pins facing down.
  • USB-C power, 5 V 1 A — any decent power bank runs it all day.

The command buttons are not backlit. On a dark stage you work from memory — which is what this sheet is for.
